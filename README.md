# 简填 · 网申助手

一个可直接加载到 Chrome / Edge 的 Manifest V3 浏览器扩展原型。资料默认保存在浏览器本地，不需要后端服务。

## 安装

1. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`）。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本文件夹 `jobfill-extension`。
4. 点击工具栏里的“简填”，进入“编辑”完善资料。

## 使用

- 可填写姓名、政治身份、院校、专业、学历、生源地、现居住地、联系方式、项目经历、荣誉奖项、校内经历、证书和技能特长。
- 不上传简历。请在资料页手动维护个人信息，所有内容保存在浏览器本地。
- 在网申页面打开插件，点击“一键填充当前页面”。插件会根据标签、placeholder、name、id 识别字段，并用绿色边框标记已填入内容。
- 弹窗中点击常用字段旁的“复制”，可快速粘贴到任意页面。

## 注意

不同招聘网站字段命名和控件结构差异很大，自动填充是辅助功能，提交前请逐项检查；资料只保存在浏览器本地。

## 测试

`tests/autofill-fixture.html` 是本地模拟网申表单，用于验证姓名、院校、政治身份、电话和项目经历的自动填写。
