# 简填 · 网申助手（JobFill）

可直接加载到 Chrome / Edge 的 Manifest V3 浏览器扩展。资料默认保存在浏览器本地，不需要后端服务。

## 它做什么

- **Word / 文本简历导入**：导入 `.docx` 或 `.txt` 简历后，先用本地规则粗解析并回填资料页；开启 AI 后会用 DeepSeek 做第二次结构化解析，明显提高姓名、院校、项目、获奖、证书等信息的识别率。
- **一键自动填写**：在网申页面打开插件，点击“一键填充当前页面”。程序扫描可见、未填写的输入框，先按本地关键词保守填写；开启 AI 后，再把“页面字段标签 + 简历资料”交给 DeepSeek 做语义匹配，按“宁缺毋滥”的策略只填有把握的字段。
- **手动维护 + 复制粘贴**：可在资料页自行填写或修改姓名、政治身份、院校、专业、学历、生源地、现居住地、联系方式、项目经历、荣誉奖项、校内经历、证书、技能特长等内容，弹窗里点“复制”即可粘贴到任意页面。

## 安装

1. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`）。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本文件夹 `jobfill-extension`。
4. 点击工具栏里的“简填”，进入“编辑”完善资料或导入简历。

## 使用

1. 首次使用：打开插件 → “编辑” → 手动填写，或点击“导入 Word 简历”选择 `.docx` / `.txt` 文件。导入结果会回填到表单，请逐项核对后再保存。
2. 到招聘网站的网申/简历页面，打开插件点击“一键填充当前页面”。已填入的字段会用绿色边框标记。
3. 弹窗常用字段旁的“复制”按钮，可快速复制到任何输入框。

## AI（可选，默认关闭）

在“编辑”页的 AI 设置中：

1. 勾选“启用 AI 解析与字段匹配”；
2. 填入你自己的 DeepSeek API Key（申请：platform.deepseek.com）；
3. 模型默认 `deepseek-v4-pro`，可按需改成 `deepseek-v4-flash` 等。

Key 只保存在本机浏览器。启用后：

- 导入简历时，简历文本会发送到 DeepSeek 用于结构化解析；
- 自动填充时，页面字段标签（不含页面里的其他个人数据）和简历资料会发送到 DeepSeek 用于语义匹配。

不启用 AI 时，扩展完全本地工作，不上传任何数据。

## 注意

- 只支持文本型 `.docx` / `.txt`；旧版 `.doc` 和扫描版 PDF 无法直接解析，请另存为 `.docx` 再导入。
- 自动填充是辅助功能。不同招聘网站的控件差异很大，提交前请逐项检查。
- 代码风格刻意保守：识别不了宁可留空，也不会把多行大段经历塞进单行“项目名称”等子字段。

## 测试

- `tests/autofill-fixture.html`：本地模拟表单，在浏览器打开后点“运行自动填写测试”，可验证本地规则对姓名、院校、政治面貌、电话、经历等的填充与不覆盖已填字段。
- `tests/sample-resume.docx`：样例简历，用于在资料页验证 Word 导入解析。
